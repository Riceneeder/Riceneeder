## IFP：一款真正懂发票的桌面管理工具

IFP（Invoice Financial Parser）是一款专为个人财务、中小企业会计、代账人员设计的**桌面端发票管理软件**

它不是又一个"发票云平台"，不是又一个需要联网才能用的小程序。它是一个**装在你电脑上、数据完全属于你、不依赖任何云端**的本地工具

> **扔进去一堆 PDF，出来一份结构化台账。验真、查重、归档、导出，全自动**

## 四大核心功能

### 1. 智能解析引擎：扔进 PDF，秒出结构化数据

IFP 内置**三层解析流水线**，这是市面上多数发票工具不具备的技术深度：

```
PDF 发票 → 官方查验 API（结构化数据，最准）
                ↓ 失败自动降级
           MinerU 文档解析（Markdown + 版面分析）
                ↓ 
           LLM 智能抽取（AI 结构化 JSON，支持 GPT-4o / 通义千问）
                ↓ 兜底
           正则引擎
```

**支持全票种**：增值税专票/普票、电子发票、数电票、机动车发票、航空行程单、铁路客票、区块链电子发票、卷票……覆盖 10+ 票种的自动识别与归一化

### 2. 发票查验：真伪一秒识别

- 对接国家税务总局查验 API，直接返回官方结构化数据
- **半自动查验模式**：自动打开税局查验页面，自动填入发票代码、号码、日期、金额，你只需输入验证码——比手动录入快 10 倍
- 查验结果自动缓存 24 小时，重复发票无需重复查验

### 3. 查重 + 归档：杜绝重复报销

- **查重**：按「发票代码 + 发票号码」唯一约束，导入时自动检测重复，支持跳过或覆盖
- **归档**：PDF 原件自动归档到本地 `年/月/` 目录，原子复制，永不丢失
- **标签管理**：自定义标签 + 费用类别（差旅/餐饮/办公/交通/住宿/通讯），多维度分类

### 4. 一键导出：四种格式，覆盖所有场景

| 格式 | 用途 |
|------|------|
| **Excel (.xlsx)** | 15 列标准台账，直接交财务 |
| **CSV** | 通用数据交换 |
| **PDF-ZIP** | 原件打包，命名规则 `{日期}_{金额}_{销售方}`，一键发给审计 |
| **Word (.docx)** | 自定义导出模板，支持循环渲染发票明细 + 金额大写转换 |

所有日期自动归一化为 `YYYY-MM-DD`，金额格式统一，不用再手动调整

## 技术亮点（给懂行的你看）

- **Monorepo 架构**：`invoice-parser`（解析引擎）+ `storage`（数据层）+ `app`（Electron 桌面端）三包独立，解析引擎可作为 npm 包单独引用
- **LLM 结构化抽取**：基于 Vercel AI SDK + Zod Schema，强制约束 JSON 输出，带交叉校验（行项合计 ≈ 不含税合计、价税合计 ≈ 不含税 + 税额）
- **官方查验对接**：国家税务总局 fileAnalysis API + barcode 查验 API，自签 CA 证书自动放行
- **Better Auth 授权体系**：支持订阅制商业化，离线 7 天宽限期，免费公测可远程控制
- **自动更新**：electron-updater 集成，用户无感知升级
